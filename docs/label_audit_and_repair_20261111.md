# 标签核验与数据修复方案（2026-11-11）

当前证据指向两个需要修正的数据问题：TUAB/TUEV 两阶段使用了不同的陷波版本，TUSL 验证集与测试集存在患者重叠。不能由 loss 暴涨或 TUSL 成绩差直接推断标签写反，也不能用模型预测替换原始标签。

合计 660,951 个实际输入文件。TI-ONE 抽样固定 seed=20261111，覆盖 5 个数据集 × 3 个划分，按原始标注类别每层最多取 20 个文件；不足 20 的类别全部检查。TUSL 的全部 300 个窗口还已通过[上一轮完整标注与加载审计](data_audit_20261111.md)。

TI-ONE 检查链：源端文件 SHA256 → CFS 文件 SHA256 → pickle 标签 → 实际验证 Loader 数值标签 → 训练 `Y_text` 的下一个 token 与忽略 padding → 推理候选答案映射。没有加载模型、启动训练或修改数据。

TUEV/HMC 的训练监督包含开头 ` (` token，而验证 prompt 已经提供该 token。核验脚本最初将“训练监督序列”等同于“验证 prompt 后的续写序列”，触发了过严断言；读取实际代码和 token 后，改为分别检查额外的 ` (` 和完整类别续写，两部分均通过。没有修改模型代码或标签来让检查通过。

Workload 的标签是任务条件，不是 `subject-info.csv` 中的计算表现好坏（Count quality）；两者是不同变量。[数据集说明](https://physionet.org/content/eegmat/1.0.0/)

## 全量标签读取方法及边界

逐文件把标签与原始标注目录/文件对照：TUAB 使用原始 EDF 的 normal/abnormal 目录；TUEV 使用对应 `.rec` 行；HMC 使用按顺序筛选的 30 秒睡眠标注行；Workload 使用原始任务编号；TUSL 使用原始 `.tse_agg`/`.tse_ag` 标注。

原始标签目录在 nccserv0 生成，再与 TI-ONE 的实际 CFS 输入逐文件对照。目录 SHA256 为 `c44a49c3e13b609ff6acea025b2f9a334cbdb7fb41dbcdd2d7545a7bb0edae7b`；扫描期间重新生成目录并核对 781 份标注文件，内容未变。源端副本的扫描不是本报告的全量结论；全量结论针对实际 CFS 输入。

全量标签审计使用只读元数据读取器，在内存中将超过 64 KiB 的二进制 EEG 缓冲区替换为同长度零字节，移除可选 FRAME 封装，保留数据操作码、memo、小型标签缓冲区及标签值，避免为检查标签额外读完全部 EEG 波形。原文件没有被改写。读取器先通过 60 个不同协议/形状/标签类型的构造用例，再与普通 `pickle.loads` 在 1,060 个真实分层样本上对照，标签、形状及通道名一致；这些样本的完整文件 SHA 也已核对。

因此全量结论针对标签字段及源标注索引一致性，**不代表全量信号字节完整性、每一窗的 EEG/标注时间对齐或原始临床标注本身正确**。全量输出中的 digest 是 label-envelope digest，不能当作原始完整 pickle 的 SHA。完整文件 SHA 的源端/CFS 比较限于上述 1,060 个样本。

HMC 另核对 151 份标注：有效 30 秒行数均等于当前代码的 `numEvents-2` 分配数，未发现这一分配假设导致的额外零标签槽位。

## 修复一：统一 TUAB/TUEV 的输入版本

当前已由原始 EDF 重建确认：阶段二训练分片使用 60 Hz 陷波；阶段三历史 pickle 仍来自 50 Hz 路径。见上一轮报告中的 120 个配对窗口及 6 个 EDF 重建结果。

具体实施：

1. 从原始 EDF 完整记录重建新的 60 Hz 数据版本，涵盖 train、validation、test；保留原窗口成员、事件索引、类别、通道顺序、0.1–75 Hz 带通及 200 Hz 采样规格。
2. 只在新目录写入，生成含 `X/ch_names`、下游原标签及来源元数据的统一样本。TUEV 的下游适配应保留 `signal/label` 接口或显式适配到同一个 `X`，不可悄悄改变类别编号。
3. 阶段二仅从新版本的 train 派生无任务标签输入；阶段三从同版本 train/validation/test 派生。以相同 float32 信号的哈希检查阶段二/三配对一致；文件序列化格式不同不要求整个文件 SHA 相同。
4. 记录处理脚本版本、来源与输出哈希、标签、通道、单位和采样率。`X` 保存 µV，Loader 仍只除以 100 一次。

不要在旧的 50 Hz pickle 上再直接叠加一次 60 Hz 滤波来冒充同一重建路径。历史结果保留并标明旧数据版本。

## 修复二：TUSL 按患者重新划分，保留全部数据

已生成一个**尚未应用**的患者划分清单。使用 EDF 名称中 TUH 患者标识分组，固定 seed=20261111，仅以窗口、类别、参考方式和通道数量的分布作分层目标，没有使用模型预测或测试成绩筛选划分。38 个患者、112 个 EDF、300 个窗口全部保留。

患者交叉为 0，21 通道窗口没有删除。新测试集中最大患者贡献 19/58 个窗口，旧测试集为 45/60。此提案是新的患者隔离实验协议，不能把新旧测试分数直接当作同一固定基准的提升。

新验证/测试集分别含有 28/55 个旧训练窗口。因此**不能沿用我们已经在旧划分上继续预训练/微调的权重，再声称对新划分独立评估**。实施后应从约定的原作者起点重新做本项目的阶段二和阶段三；原作者权重的训练数据来源仍需按其发布说明界定。三个训练 seed 使用同一份固定新划分。

若只做最小修补，可将那个与 test 同患者的 validation 记录整体归入 test，保持旧 train 成员不变；但这仍保留测试集仅 3 个患者和极少 seizure 窗口的问题，不能替代上面的患者分层方案。

## 修复后如何处理 loss 暴涨

先锁定数据版本与划分，再对阶段三峰值学习率做单变量短程对照；保持其它设置一致，以验证集选择配置。增加每数据集的 instruction loss、text loss、梯度范数和异常 batch 的样本标识记录，才能把尖峰定位到具体数据或优化步骤。当前审计没有证明 loss 暴涨由错标导致，也没有证明统一滤波后尖峰必然消失。

负均值或幅值超出 ±100 µV 本身不等于错标。对大幅值、标注边界和持续高损失的候选窗口，应回看原始 EDF 的单位、参考方式、波形和事件时间；若怀疑原始临床标注，需要 EEG 专业人员盲审。不要为了让数值落入某个范围而直接裁剪所有波形，也不要用模型预测自动重标。

本次只生成审计报告和修复提案，未改写数据、未重标标签、未启动新的训练。
