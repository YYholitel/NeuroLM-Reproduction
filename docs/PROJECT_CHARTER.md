# 项目范围与协作

## 目标

复现 [NeuroLM 论文](https://arxiv.org/pdf/2409.00101) 的下游实验结果。优先使用作者发布的 NeuroLM-B 版本建立可运行的端到端流程，然后比较 TUAB、TUEV、SEED、HMC、Workload 和 TUSL 六项任务。若数据、权重或计算资源限制导致某项无法完成，记录原因与已验证的范围，不将替代实验写成论文结果复现。

## 交付物

1. 固定版本的作者源码、环境和数据来源清单。
2. 可重复执行的数据预处理、运行与评估命令。
3. 每项任务的随机种子、样本数、指标、运行日志和论文对照。
4. 公开 GitHub 仓库中的复现报告与必要脚本；不上传受限数据或权重。

## 管理规则

- 总负责人维护结构、任务、进度、决策和 GitHub 同步。
- 实现任务写明输入、输出、完成标准与验证证据，再交由协作者或其他 agent。
- 任何对作者代码、数据划分或指标计算的修改都记录差异和原因。
- 仅把独立运行得到且可追溯的数字填入复现结果列。

## 当前条件

- 作者源码固定在 `0cda9876d8ce6ee07ed0c43eee5e9a6f5c24b177`。
- 可用服务器为 8 × RTX 3090（每张 24 GB）；论文实验使用 8 × A100（每张 80 GB），因此需要先验证显存和批量配置。
- 原始数据位置、访问权限与模型权重文件均待核对。
