# 数据检查：TUSL 标注与加载、两阶段滤波版本

检查日期：2026-11-11，Asia/Shanghai。实际检查输入数据与运行加载器，未修改数据、权重或训练配置。三路训练/评估任务在本次检查时均已成功结束。

## 结论

1. TUSL 的 112 份原始标注、300 个窗口及实际加载链路通过检查。标签与答案映射、21/23 通道顺序、X/100、padding 和 mask 未发现错误。
2. TUAB/TUEV 阶段二与阶段三存在滤波版本不一致。各抽查 60 个独立 EDF 的训练窗口，全部数值不同；各挑选 3 个窗口回到原始 EDF 重建，阶段二全部精确匹配 60 Hz，阶段三全部精确匹配 50 Hz。
3. TUSL 按文件划分未实现完全的患者隔离：验证/测试共享 1 个文件名患者标识。测试集只有 3 个患者标识，60 个窗口中的 45 个来自同一患者标识。

这些发现不能单独证明此前 loss 尖峰或所有下游错误的原因。当前结果可以作为有上述限制的实验记录，不能称为已消除数据问题的患者独立复现结果。

## 检查方法和覆盖范围

- nccserv0：独立读取 112 份 TUSL 原始 `.tse_agg/.tse_ag` 标注和 EDF 头信息，核对标注哈希、时间窗、标签、通道顺序、REF/LE 和文件划分。未重新计算全部原始 EDF 内容哈希。
- TI-ONE：逐个读取全部 300 个 TUSL pickle，核对文件哈希和原始标注；对 174 个训练分片再次检查 tar 字节哈希及数组一致性。
- 用本次实际 `code/dataset.py` 和 `author/downstream_dataset.py` 加载每个 TUSL 样本；训练及推理两种模式都检查，并独立构造期望的 patch 顺序、通道 ID、时间 ID、padding 和 attention mask。
- 比较 TUAB/TUEV 两阶段输入：固定随机种子 20261111，每个数据集选 60 个独立 EDF，各选一个现有训练窗口。此项是训练划分抽样，不是所有划分的全量审计。
- 对每个数据集按差异从小到大选择最小、中间、最大的三个窗口，在 nccserv0 分别以 50/60 Hz 从原始 EDF 重建。nccserv0 对应下游 pickle 的文件哈希与腾讯端一致。

## TUSL 划分问题与分布

患者标识取 EDF 文件名第一个下划线前的 TUH 标识；本次没有连接外部患者身份登记表。

| 划分 | EDF | 窗口 | 患者标识数 | background / seizure / slowing | REF / LE |
|---|---:|---:|---:|---|---|
| Train | 67 | 174 | 26 | 50 / 77 / 47 | 119 / 55 |
| Validation | 23 | 66 | 10 | 17 / 20 / 29 | 66 / 0 |
| Test | 22 | 60 | 3 | 33 / 3 / 24 | 60 / 0 |

训练/验证、训练/测试均未发现患者标识交叉。验证/测试有 1 个患者标识交叉；该标识贡献测试集 45 个窗口、验证集 1 个窗口。录音文件本身没有跨集合重复，说明仅检查 EDF 文件名是否重复不足以验证患者隔离。

55 个新增 LE 窗口全部位于训练集。实际样本没有被删除，但参考方式在各划分的分布不同。测试集 seizure 仅 3 个窗口，且大部分测试窗口集中于一个患者标识，因此少量错误即可显著影响指标，不能将 60 个窗口视作 60 个独立患者。

幅值检查另发现部分窗口较大，最大窗口绝对幅值 P99 约 1652.32 µV。这是后续波形审阅的候选，不作为单位错误或删除样本的判据。本次已验证加载缩放一致，但没有穷尽每个窗口的生理信号质量。

## TUAB/TUEV 两阶段滤波差异

| 数据集 | 独立 EDF / 配对窗口 | float32 数值相同 | 差异 RMSE 中位数（µV） | 阶段二 / 三的 60 Hz 功率比中位数 |
|---|---:|---:|---:|---|
| TUAB | 60 / 60 | 0 | 0.7812 | 0.4085 / 1.7980 |
| TUEV | 60 / 60 | 0 | 1.2233 | 0.4318 / 3.4834 |

功率比仅作诊断：Welch `fs=200, nperseg=400`，60±0.5 Hz 平均功率除以距 60 Hz 2–5 Hz 邻域平均功率，先取每个窗口通道中位数，再取窗口中位数。该比值不是统一的信号合格阈值。

原始 EDF 重建提供了比功率谱更直接的版本证据：

| 重建样本 | 50 Hz 路径 | 60 Hz 路径 |
|---|---|---|
| TUAB 3 个训练窗口 | 与阶段三旧 pickle 数值完全一致，RMSE=0 | 与阶段二 float32 信号哈希完全一致 |
| TUEV 3 个训练窗口 | 与阶段三旧 pickle 数值完全一致，RMSE=0 | 与阶段二 float32 信号哈希完全一致 |

重建使用 MNE 的完整记录滤波，再重采样、按原窗口索引截取，未仅对切出的短窗重新滤波。最大差异样本中，两种路径的 RMSE 分别约 141.56 µV（TUAB）和 327.08 µV（TUEV），不能把所有差异都看成浮点误差。

此前 60 Hz 修改落实到了阶段二转换脚本和预训练分片；修改脚本没有自动覆盖阶段三继续读取的历史 pickle。当前六个重建样本证实了这条路径差异。验证/测试划分的全部文件仍需在新数据版本中统一处理和清单校验，不能由这次训练样本抽查推断已经处理完成。

## 后续修正顺序

1. 为 TUAB/TUEV 生成统一的 60 Hz 数据版本，固定通道顺序、单位、窗口及原划分成员；阶段二和阶段三都从同一受控版本派生，并分别保存哈希清单。
2. 在保留 TUSL 全部 300 个窗口的前提下，处理验证/测试患者重叠，评估测试患者过度集中与类别不平衡。若重划分将旧训练患者放入新验证/测试集，不能沿用已见过这些患者的阶段二权重声称独立评估。
3. 完成数据版本检查后，再以验证集开展学习率等对照实验。当前测试结果不用于选择超参数。
